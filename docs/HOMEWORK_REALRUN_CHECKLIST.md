# 云作业真机首验清单

离线套件（`scripts/check_*.py`）只覆盖解析、提取、写入打桩、闸门与配置往返；
真机上还需要确认浏览器交互。首次真机跑作业时按下面顺序做，**每步都要留证据**
（日志片段或截图）。

## 前置

1. `start-UnipusAI-Helper.bat` 启动，确认工作台显示「就绪」，浏览器已登录。
2. 打开 `config.json` 确认：`target_accuracy` 是 int、`homework_submit` 是 bool、
   `homework` 是对象（不是字符串）。
3. 点「扫描作业」，确认任务列表出现作业，**单元显示为课程名**。

## 必查 4 项（每项留证）

| # | 操作 | 通过标准 | 留什么 |
|---|---|---|---|
| 1 | 选一份**可重做/不计分**的作业 → 开始处理 | 日志出现「作业页共收集 23 个题目容器」（数字随作业变化），逐题有题型 | 日志 20 行 |
| 2 | 段匹配题（41–50 一类） | 写入的是**单个字母**，页面上下拉/输入框都显示已填 | 页面截图 + 日志「第 3 题字母 …」 |
| 3 | 填完后提交前 | 若还有空位，日志是「还有 N 个空没填（下拉 X / 输入 Y），先不提交」 | 日志 3 行 |
| 4 | 提交 | 日志「提交已确认：<作业名> → 已批阅」（或「批阅中」）；作业从「待作答」消失 | 日志 5 行 + 作业列表截图 |

## 中止条件（任一命中立即停止，不要继续点提交）

- 出现「⚠ 未验证强设（不计成功）」**且**该题最终仍被计为成功 → 说明闸门又被绕过。
- 日志出现「作业页共收集 N 个题目容器」但 N 明显小于页面大题数（漏节）。
- 第 2 项写进输入框的是单词/整段而不是单个字母。
- 提交后 60 秒内没有「提交已确认」，却打印了「已提交作业」。
- 页面出现平台自己的错误弹窗（如「作答超时」「已提交过」）。

## 出问题时要贴的东西

1. `logs/ucampus_*.log` 里从「开始处理作业」到「提交未确认/已提交作业」整段；
2. 作业页截图（含答题卡状态）；
3. `config.json` 的 `target_accuracy` / `homework_submit` / `homework` 三个键
   （**不要贴账号、密码、api_key**）。

## 已知限制

- `PARAGRAPH_MATCH` 不参与「故意做错」，60% 目标只作用在其余题型上。
- 60% 的分母是「空位近似」（下拉/填空按空位数、其余按 1 题 1 分），不是平台真实分值；
  目标与实际得分可能有 ±10 分以内的偏差。
